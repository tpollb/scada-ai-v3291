# Changelog

## [3.3.0] - 2026-08-21

### ✨ Добавлено

- **Полноценная система лицензирования (Offline):**
  - Валидация JWT-токенов с подписью RSA-2048 (`core/license/`)
  - Поддержка Grace Period (по умолчанию 3 дня) с визуальными предупреждениями в UI
  - Ограничение количества одновременных пользовательских сессий (in-memory tracking с таймаутом 30 мин)
  - Feature gates — модули загружаются только если они разрешены текущей лицензией
- **UI управления лицензией:**
  - Новый store `frontend/src/stores/license.ts` для управления состоянием лицензии
  - Компонент `LicenseBanner.svelte` — предупреждения при grace period / истечении
  - Обработка HTTP 402/403 в `api.ts` через customFetch wrapper
- **CLI-инструменты:**
  - `scripts/generate_keys.py` — генерация RSA-2048 ключей
  - `scripts/generate_license.py` — генерация файлов `.lic`
- **Middleware:**
  - Глобальная проверка срока действия лицензии для всех API-запросов
  - Возврат HTTP 402 при истечении (после grace period)
  - Возврат HTTP 403 при превышении лимита пользователей
- **Документация:**
  - Новый раздел `docs/LICENSING.md` с полным описанием системы
  - Обновлён `MODULES.md` — добавлена таблица соответствия лицензий и модулей

### 🛠️ Изменено

- Увеличен таймаут HTTP-клиента (ky) на фронтенде до 180 секунд для поддержки долгих LLM/DB запросов
- Исправлены проблемы с CORS при локальной разработке (Vite + FastAPI)
- Переход на `customFetch` в `api.ts` для надёжного перехвата HTTP-ошибок

### 📚 Документация

- Создан `docs/LICENSING.md` — полное руководство по системе лицензирования
- Обновлён `MODULES.md` — добавлен раздел о feature gates
- Обновлён `CHANGELOG.md` — добавлена запись о v3.3.0
- Обновлены `Project_full_description.md` и `ARCHITECTURE.md` — версия 3.3.0
